# Security policy

SplitMate is a local portfolio project, not a supported hosted financial service. Do not use real payment credentials or expose the provided development servers publicly.

Before publication, enable GitHub private vulnerability reporting in repository settings. If enabled, use the repository Security tab to report a suspected vulnerability privately. Do not put passwords, session cookies, CSRF tokens, private database records or exploit details in a public issue. No private reporting address or response-time commitment is configured yet.

See [security review](docs/security-review.md) for threat boundaries, dependency-audit results and unresolved limitations. No production-readiness, penetration-test or vulnerability-free certification is claimed.
